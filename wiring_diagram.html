🔌 ESP01 + MH-Z19 CO2传感器 + LED报警 接线图

⚠️ 重要提醒：MH-Z19需要5V供电，但ESP01 GPIO是3.3V电平！
必须使用电平转换或分压电阻，否则会损坏ESP01！

📦 所需元器件

  • ESP01 模块
  • MH-Z19 CO2 传感器
  • LED灯一个
  • 电阻：1kΩ + 2kΩ（分压用）
  • 或双向电平转换模块（推荐）
  • 杜邦线若干

🔧 接线表

ESP01 连接方式 MH-Z19 / LED
VCC (3.3V) → 直接连接 MH-Z19 Vin (3.3V供电)
GND → 共地 MH-Z19 GND
GND → 共地 LED 负极
GPIO1 (TX) → 直接连接 MH-Z19 RX
GPIO3 (RX) → 经1kΩ+2kΩ分压 → MH-Z19 TX
GPIO2 → 串联 220Ω 电阻 → LED 正极

⚡ 分压电阻连接方法

GPIO3 ← MH-Z19 TX 信号必须降压：

MH-Z19 TX (5V) → 2kΩ 电阻 → 分点 → 1kΩ 电阻 → GND

分点处连接 ESP01 GPIO3 (RX)
计算：5V × (1kΩ / (1kΩ + 2kΩ)) = 1.67V ✓ 安全

💡 LED 连接方法

GPIO2 控制报警灯：

ESP01 GPIO2 → 220Ω 电阻 → LED 正极 → LED 负极 → GND

📊 接线示意图

ESP01
GPIO1, GPIO2, GPIO3, GND, 3.3V

↓ GPIO1(TX) ──────────→ MH-Z19 RX
↑ GPIO3(RX) ← 1kΩ+2kΩ分压 ← MH-Z19 TX
↓ GPIO2 → 220Ω → LED 报警灯

⚠️ 注意事项

  • 烧录程序时：先断开MH-Z19的TX/RX连接，避免干扰
  • GPIO2：板载有蓝色LED，可直接使用或外接LED
  • 共地：所有模块必须共用GND
  • 供电：MH-Z19需要5V供电，ESP01需要3.3V供电（不要接错！）

🔄 替代方案：双向电平转换模块

如果手边有双向电平转换模块（如BSS138模块），可以更方便地连接：

ESP01 (3.3V) 电平转换模块 MH-Z19 (5V)
HV ← 5V供电 → LV
GND ← 共地 → GND
GPIO1 (TX) LV1 → HV1 RX
GPIO3 (RX) HV2 → LV2 TX
